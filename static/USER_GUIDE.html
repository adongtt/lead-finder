一、登录与账号

打开网站后进入登录页，输入用户名和密码即可进入主界面。

  • 角色分为 管理员（admin） 和 业务员（sales）
  • 管理员可查看所有人的搜索记录和联系人
  • 业务员只能查看自己的数据
  • 首次使用请管理员在 users.json 中创建账号

1.1 左侧导航栏

登录后左侧固定导航栏可快速切换：

入口 说明
搜索 进入首页，选择搜索模式
历史结果 查看所有搜索记录并下载 CSV/Excel
数据看板 查看本周线索、已联系、成交、待跟进数量
已联系客户 CRM 跟进列表，查看跟进历史、修改状态
搜索模板 常用 Apollo / 关键词 / Google Maps 搜索模板，一键填入
批量工具 批量验证 CSV、批量导入域名挖邮箱
系统状态 查看 API 密钥配置与数据库连接状态
问题反馈 提交搜索失败、界面问题或功能建议
使用手册 打开本手册
更新日志 查看最近功能更新（主界面左侧边栏底部）
退出 退出登录

在窄屏或移动端，左侧导航会折叠为图标模式，更新日志自动隐藏。

二、搜索模式总览

页面顶部有 5 种搜索模式切换：

模式 适用场景 数据来源
Apollo 搜索 按产品关键词/域名找采购决策人 Apollo.io
供应商门户 已知一批域名，扫描采购/供应商页面 网站主动扫描
Google Maps 搜索 按地区找线下商家 Google Places API
关键词搜索 用 Google 搜索找 B2B 客户 DuckDuckGo（优先）/ 浏览器抓取 / SerpAPI（备用）

三、Apollo 搜索（推荐）

3.1 适用场景

  • 知道目标行业，但不知道具体公司
  • 想直接找到 Buyer / Purchasing Manager / Procurement Manager
  • 需要按国家、州、城市、公司规模精准过滤

3.2 填写步骤

  1. 公司关键词：输入产品或行业英文词，例如 sporting goods、football gloves
  2. 目标职位：按住 Ctrl/Cmd 多选，建议只选采购相关职位
  3. 公司规模：推荐 2-50 人（小经销商最精准）
  4. 目标地区：按国家/州/城市/邮编逐级精确
  5. 最大结果数：默认 100，Apollo 每页最多 100 条
  6. 保留无邮箱客户：适合电话开发时勾选
  7. 同时扫描采购/供应商页面：勾选后会进一步探测该公司的 procurement / vendor 页面

3.3 已有客户扩量

在 📥 已有客户域名扩量 框中粘贴合作客户域名（每行一个），Apollo 会找出这些公司的联系人，用于：

  • 老客户深挖
  • 相似客户拓展

3.4 提高精准度技巧

  1. 关键词用 sporting goods 比 football gloves 更精准
  2. 职位只选 Buyer / Purchasing / Procurement / Sourcing，别选 CEO
  3. 结合地区过滤，减少不相关国家结果

四、关键词搜索

4.1 适用场景

  • 有明确的产品词
  • 想发现 Google 上的分销商、进口商、零售商

4.2 填写步骤

  1. 关键词：例如 baseball gloves distributor
  2. 搜索页数：默认 20 页，越多结果越全但越慢
  3. 最大域名数：限制处理的域名数量，留空则无限制
  4. 排除域名：跳过竞争对手或不想要的域名，逗号分隔
  5. 目标国家/地区：按住 Ctrl/Cmd 多选 TLD，如 .de、.uk、.au

搜索引擎优先级：系统默认优先使用 DuckDuckGo，未安装或失败时自动使用浏览器抓取，配置了 SerpAPI 时作为最后备用。若 SerpAPI 触发速率限制，界面会提示 "API 请求过于频繁"，此时可稍后重试，或临时移除 config.yaml 中的 serpapi_key 以强制使用 DuckDuckGo。

4.3 更多选项

点击 更多选项 ▼ 展开：

选项 说明
深度搜索 跳过前 5 页，避开大品牌和 Wikipedia
排除大平台 过滤 Alibaba / ThomasNet / Yelp 等目录站
高级搜索语法 标题必须包含关键词，结果更精准但数量更少
严格模式 一键开启大平台排除 + 高级语法 + 提高关联度门槛
关联度最低分 调高可过滤低关联站点
同时搜索 Amazon 品牌 从 Amazon 热门产品中发现潜在品牌客户
同时扫描采购/供应商页面 搜索完成后扫描 procurement / vendor 页面

4.4 推荐关键词模板

页面提供快速模板：棒球手套分销商、橄榄球装备进口商、体育用品批发商美国等。

五、Google Maps 搜索

5.1 适用场景

  • 想找某个地区的线下经销商或门店
  • 需要电话、地址、评分等线下信息

5.2 填写步骤

  1. 关键词：产品词，例如 baseball gloves
  2. 目标地区：例如 USA、Germany、Southeast Asia
  3. 可勾选 保留无邮箱客户 和 同时扫描采购/供应商页面

六、批量导入域名

6.1 适用场景

  • 已有展会名单、海关数据、客户名单
  • 直接对域名列表挖掘邮箱

6.2 填写步骤

  1. 切换至 批量导入域名 模式
  2. 在文本框中粘贴域名，每行一个或逗号分隔
  3. 可勾选 保留无邮箱客户 和 同时扫描采购/供应商页面

七、供应商门户扫描

7.1 适用场景

  • 已知一批目标公司域名
  • 想批量查找这些公司的采购入口、供应商注册通道

7.2 扫描页面

系统会自动扫描以下常见路径：

/procurement
/purchasing
/sourcing
/become-a-supplier
/become-a-vendor
/supplier-portal
/vendor-portal
/supplier-registration
/sell-to-us
/work-with-us
/partner-with-us

7.3 提取信息

  • 采购/供应商页面 URL
  • 页面标题
  • 页面上的采购邮箱
  • 申请表单链接
  • 页面摘要

7.4 注意事项

  • 扫描速度与域名数量成正比
  • 勾选“同时扫描采购/供应商页面”的 Apollo / 关键词搜索也会触发类似扫描
  • 部分公司可能没有专门的供应商页面

八、结果查看与导出

8.1 结果表格

搜索完成后页面会显示前几条结果预览，包含：

  • 邮箱、姓名、职位、国家
  • 电话、公司、域名
  • LinkedIn 链接
  • 来源类型
  • 公司简介
  • 采购/供应商页面（如启用扫描）

8.2 查看全部

点击 查看全部 进入结果详情页，可查看完整列表。

8.3 导出

  • 结果详情页提供 下载 CSV 按钮
  • 历史搜索记录也可随时下载
  • 搜索历史支持导出 Excel，并可按职位过滤

8.4 批量验证

在结果详情页顶部可点击 批量验证，系统会对当前结果中的客户进行三项检查：

检查项 说明
域名存活 域名是否能正常解析/访问
邮箱有效 通过 ZeroBounce 重新验证邮箱（需配置密钥）
公司活跃 网站内容是否显示公司仍在运营

验证过程中页面会保持连接并每 5 秒发送一次心跳，避免长时间安静的验证任务被代理/浏览器断线。若验证失败，可点击 重新验证 再次执行。

九、CRM 跟进

9.1 标记已联系

在结果列表中点击 标记已联系，系统会记录：

  • 联系时间
  • 跟进人
  • 客户邮箱和域名

9.2 查看客户详情

点击 跟进 按钮可查看：

  • 当前状态
  • 完整跟进历史
  • 下次跟进时间

9.3 添加跟进记录

在客户详情弹窗中：

  1. 选择状态：已发邮件 / 已回复 / 已报价 / 谈判中 / 成交 / 放弃
  2. 填写备注
  3. 设置下次跟进时间
  4. 点击 保存跟进

9.4 跟进提醒

数据看板会显示 待跟进 数量，方便安排日常工作。

十、写开发信

10.1 打开邮件面板

在结果列表中点击 发邮件，右侧会弹出邮件撰写面板。

10.2 选择模板

提供 3 种模板：

  • 品牌 / 分销商（欧美）：通用型开发信
  • 采购经理：针对采购角色
  • 跟进邮件：二次跟进

10.3 邮件签名

在右侧边栏 邮件签名 卡片中填写：

  • 您的姓名
  • 公司名称
  • 电话 / WhatsApp

点击 保存签名 后会自动带入邮件正文。

10.4 复制邮件

写好邮件后点击 复制邮件，即可粘贴到邮件客户端发送。

十一、数据看板

右侧边栏显示：

指标 说明
本周线索 本周搜索到的线索总数
已联系 已标记为联系的客户数
成交 状态为“成交”的客户数
待跟进 需要继续跟进的客户数

十二、常见问题

Q1：为什么 Apollo 搜索结果里有很多不相关的公司？

Apollo 的匹配逻辑较宽泛，工具已经通过行业关键词、职位、地区等维度自动过滤和打分。建议：

  • 使用更精准的行业词，如 sporting goods
  • 只选采购相关职位
  • 添加地区过滤

Q2：为什么有些域名没有邮箱？

可能原因：

  • 该公司未在 Hunter / Apollo 数据库中
  • 使用的是通用邮箱，被过滤掉了
  • 可勾选 保留无邮箱客户，用于电话开发

Q3：扫描采购/供应商页面会不会很慢？

会额外增加一些时间。每个域名会并发扫描多个常见路径。影响速度的因素：

  • 域名数量
  • 目标网站响应速度
  • 网络环境

建议：

  • 少量域名时勾选
  • 大量域名时先用普通搜索筛选，再单独使用供应商门户模式

Q4：搜索失败或超时怎么办？

  • 检查 API 密钥是否配置正确（config.yaml 或环境变量）
  • 减少搜索页数或最大域名数
  • 关键词搜索出现 "API 请求过于频繁" 时，说明 SerpAPI 触发了速率限制（HTTP 429），系统会自动降级到 DuckDuckGo，可稍后重试；也可临时移除 config.yaml 中的 serpapi_key 强制使用 DuckDuckGo
  • 若长时间卡在 "正在验证..."，批量验证已增加心跳保活和 60 秒超时保护，可点击 重新验证
  • 查看日志框中的具体错误信息

Q5：如何导出 Excel 而不是 CSV？

在历史搜索列表或结果详情页，点击 导出 Excel 即可下载 .xlsx 文件。

Q6：管理员如何查看所有人的数据？

管理员登录后：

  • 搜索历史页面显示所有人的搜索记录
  • 已联系客户页面显示所有人的跟进记录
  • 业务员只能看到自己的数据

十三、左侧导航其他工具

13.1 已联系客户

左侧导航进入独立的 CRM 列表页，可：

  • 按邮箱 / 域名 / 状态筛选客户
  • 查看单个客户的完整跟进历史
  • 修改状态、添加备注、设置下次跟进时间

13.2 搜索模板

把常用搜索组合做成模板卡片，点击后自动跳转到搜索页并填入参数。适合新员工快速上手，也避免每次重复填写。

13.3 批量工具

  • 批量验证 CSV：上传已有线索 CSV，对域名存活、邮箱有效、公司活跃进行批量验证
  • 批量导入域名：粘贴域名列表直接挖掘邮箱，跳过搜索引擎环节

13.4 系统状态

查看各 API 密钥是否已配置（不显示密钥内容）、配置来源以及数据库连接状态，方便排查环境问题。

13.5 问题反馈

遇到搜索失败、验证异常、界面问题或有功能建议时，可填写反馈类型与描述提交。反馈会保存为 JSON 文件，管理员可在服务器 feedback/ 目录查看。
